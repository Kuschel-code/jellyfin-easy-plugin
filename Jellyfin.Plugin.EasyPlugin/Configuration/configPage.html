Easy Plugin

Choose which plugin entries appear in the admin sidebar and in what order. Use the arrow to open a plugin's settings inline. Changes are saved automatically and apply to the sidebar right away.

Enable sidebar tweaks
When off, the sidebar is left untouched.
Show a filter box in the sidebar
Adds a search field above the plugin list — handy once you have many plugins.
A separate layout per user
Off: everyone shares one layout. On: each admin arranges their own, falling back to the server default until they change something.

Toggle whether each plugin appears in the sidebar, then reorder with the ▲/▼ buttons or by dragging the handle. Moving an entry onto a group puts it inside; moving it past the end takes it back out. Create a group and give it a name (and optionally a Material icon such as tune) — in the sidebar it becomes a collapsible header with its plugins nested underneath. Rename any entry by typing over its label. Plugins that aren't normally in the sidebar are under Add another plugin (marked extra).
